# Cisco Packet Tracer – Multi-Segment Network Design

## Project Overview

This project involved designing and configuring a multi-segment enterprise network using Cisco Packet Tracer as part of my Computer Networks coursework at the University of Texas at San Antonio (UTSA).

The network was progressively developed through multiple assignments, culminating in a larger topology incorporating internal network segments, routing infrastructure, server services, network management, and external connectivity.

## Network Architecture

The final topology includes:

- **Network Switching:** Multiple Cisco Catalyst 3650 switches connecting end-user devices and network segments.
- **Routing:** Cisco ISR4331 core and ISP routers providing connectivity between internal and external networks.
- **DHCP:** Dedicated DHCP server for network address assignment.
- **DNS:** Internal DNS server and external Web/DNS server.
- **DMZ:** Separate network segment containing web and DNS server infrastructure.
- **Network Management:** Dedicated management network and Packet Tracer Network Controller.
- **End Devices:** Multiple desktop computers and laptops distributed across network segments.

## Implementation

The network was constructed incrementally, with each assignment introducing additional networking concepts and configuration requirements.

The final project involved connecting multiple network segments, configuring routers and switches, implementing server infrastructure, and establishing connectivity to an external ISP network.
